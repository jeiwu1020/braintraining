# 夜市選菜會手機橫向單頁布局

本項以 `6fef10ac4c3cd8ceebd1f64d45e3c9104169dced` 為基準，只改進場後的夜市橫向布局。五款選單圖框高度另見 `MENU_ART_HEIGHT.md`，兩項使用不同CSS、測試與diff。

## 問題與實際量測

基準CSS的橫向 `min-height:430px` 與共用 `min-height:330px`，加上頁首後超過較矮的可視高度。頁面外框雖沒有document overflow，遊戲main仍需捲動，下排牌只露出頂部。進階 `min-height:460px` 的規則實際只套用直向，不是此處橫向原因。

在Chromium 844×390中，基準頁首59px、遊玩區430px，遊玩區底端489px、下排牌底端438px，超出畫面。修正後頁首49px、遊玩區341px，四張牌及資訊區都配置在可視高度內。這是本機瀏覽器重現，不是iPhone實機量測。

參考圖 `IMG_6034.jpeg`（Library ID `libfile_efea4c1bfe908191b997b3f944e47605`）透過支援流程準備下載，明確本機目的地 `/workspace/night-market-reference/IMG_6034.jpeg`。當次下載工具首次及一次重試均exit 1，錯誤完全相同：`library file transfer failed: download failed`。本機檔案不存在，因此本執行器未直接看到參考圖。轉述的截圖觀察沒有被當作本機讀圖證據，也沒有假定其他環境路徑可讀或猜測網址。

## 調整範圍

- 新規則只套用 `.pg-night` 且橫向、高度不超過600px、寬度不超過1100px；設定畫面、AI選項、直向與一般桌面沒有套用這組布局。
- 頁首改為緊湊單行標題與模式／輪次，保留返回、撤回、規則、選項及44px觸控區。
- 手機橫向用更明確、後置的夜市selector取消430px／共用330px固定下限，讓遊玩區依既有可視高度變數配置。目標範圍以外保留原CSS行為；沒有改動共用viewport hook或safe-area機制。
- 左側保留雙方餐盤與食物數、當輪兩個訂單條件／分數／符合狀態、2×2四張牌。牌庫各食物剩餘數與基本計分帶在底部並排，減少層層堆疊。
- 右側控制面板按內容自然排高，確認／取消並排，當前玩家、預選基本分變化、最近拿取與牌庫總數保留。
- 回合／最終結算仍顯示當輪訂單、兩隊基本菜分／訂單加分／總分與首輪分數。最緊高度下亦檢查最後一手文字及計分明細在容器內完整可見，透過減少容器留白解決，沒有整體縮放或刪除計分文字。
- `NightMarket.tsx`、規則、AI、難度設定、session格式、選牌／確認／取消／撤回與鍵盤2×2導覽均未改動。

## 驗證規格與保存方式

`docs/qa/night-market-landscape-browser.mjs` 使用正式元件與原引擎產生的有效journal。每個測試使用獨立Chromium context，未呼叫 `sessionStorage.clear()`；測試既有格式且未帶aiDifficulty的續局，並逐位元組確認旋轉、取消、規則、選項、返回續玩及重新整理不改寫舊journal。另保留無關storage sentinel。

- 一般／進階 × 單人／雙人；真實設定流程新局與舊格式續局。
- 首輪／第二輪：未選牌、已選牌、電腦回合（單人）；回合結算與最終結算均包括最後一手揭示前及分數明細揭示後。
- 844×390、896×414、932×430；補充768×353、844×320、896×344、932×360。
- 透過明確visualViewport shim模擬844×390可視300px、896×414可視324px、932×430可視340px；另測可視320px且左右44px、底部16px安全邊界。
- 390×844直向與1440×900桌面作回歸比對。
- 520組量測涵蓋上述40個流程／階段與13種視窗；驗證所有主要資訊／操作在可視範圍、四張牌與按鈕至少44px、main及控制區不需捲動、結算文字也不需局部捲動。電腦只在按下揭示後確認一手，AI沒有自動出招。

基準另以detached worktree啟動，未重啟執行環境或覆蓋目前修改。前後JSON、三個指定橫向尺寸的未選牌／選牌／回合與最終結算截圖，及獨立binary diff保存在本批審查包。

最終production preview的520組量測全數通過，基準相同520組中有416組出現裁切／捲動等失敗；直向／桌面72組既有續局幾何與基準完全相同。實測主要按鈕最小46×44px；最後一手與結算明細也無局部捲動。單人AI仍只在帶領者揭示後確認一手，舊journal及無關storage均保留。

舊單元測試曾固定要求430px可捲動區域，與本次單頁需求相反，因此移除該字串斷言，改由上述實際幾何回歸驗證；其餘最後一手、AI揭示、餐盤、牌庫及續局互動測試保留。

完整測試、typecheck、build與最終量測結果列於本批審查包總報告。原始參考圖未能下載；所有新截圖都是Chromium模擬，不是iPhone、iPad或實體Safari驗收。正式站UI與實體iOS需另行驗收。
