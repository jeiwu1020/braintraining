# 2026-10-13 團體腦訓練更新

本版涵蓋14款團體遊戲，經使用者試玩確認後發布。以病人口述、帶領者操作與共同討論為主要情境；活動分數不是認知能力或治療成效的標準化量表。

## 主要改動

- 共用介面：確認後提交、防重複觸發、完整復原、換局及離開確認；離開按鈕明確寫「確認離開」。
- 字詞路徑：9張語意與多路徑題，整詞提案及主持判斷延伸詞。
- 移動火柴棒：12題、七段圖、來源與目的預覽；僅禁止拿取加號橫棒。
- 邏輯線索偵探：9題唯一解，增加順序、排除與反證關係。
- 數織彩繪：9幅可辨識且唯一解的圖像，完成後顯示圖名及顏色。
- 合作踩地雷：54個原盤、三階6／7／8雷，限制大型零區但保留正常連鎖、首格周圍安全與免猜推理。
- 取石子策略：保留原3／4／5與1／3／5／7完整開局、一般與反向規則，修正提示計分與復原。
- 河內塔：保留原3／4盤A到C直接移動，修正完成步數、回合與分數復原。
- 塞車解謎：36個不同結構題；一般8–14、進階15–25最短整步，拖曳／按鍵並存及清楚車號。
- 圍棋：保留原9／13／19路、三模式、直接落子與自動AI；原題4題補6條驗證變化，其餘標示首手參考；標準版棋盤按實際容器縮放。
- 拉密魔術牌：12題，驗證完整桌面、殘組與最大出牌量，接受並列方案。
- 麻將湊牌大師：12題，局部組牌、全部進張及捨牌比較；不冒稱整手胡牌。
- 繽紛形色棋：9題，橫直雙條件與公開下一張的兩步比較。
- 歡樂排七接龍：12題，合法接牌、公開短局及延後替對方開路的規劃。
- 經典撿紅點：12題，實際配對收牌與公開下一張的兩步總分比較。

## 驗證與邊界

- 123個測試檔、772項通過；1項因原一般介面未提供讓子控制而條件略過，同項在橫向介面執行。
- TypeScript、production build與獨立審查通過；題庫依類型進行唯一解、最短路、完整枚舉或獨立規則交叉驗證。
- 使用者已確認圍棋桌面裁切修正；自動DOM驗證不代替所有手機尺寸、觸控與旋轉的實機檢查。
- 題庫有限；提示知識以分頁內題號記錄。關閉分頁或清除資料後，分數不能證明未看過答案。
- 圍棋補充變化只涵蓋明示分支，不宣稱窮盡所有最佳應手；對局結算仍需共同核對死子。

驗證命令：`npm test -- --maxWorkers=1`、`npx tsc --noEmit`、`npm run build`。
