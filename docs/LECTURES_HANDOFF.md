# 職能講座第一堂：候選驗收與接入說明

狀態：本地候選，尚未推送、部署或取代正式站。

## 功能範圍

- 原首頁「桌遊新樂園」後加入同風格的「職能講座」入口。
- 獨立主題首頁展示六類生活主題；16 堂為整體規劃，目前只有第一堂可開始，其餘明確標示規劃中。
- 第一堂「可疑訊息，下一步怎麼做？」有 24 個完整教學畫面：約 60 分鐘的開場、三方法、逐步示範、三情境討論、休息、新情境、求助對話和回顧。
- 成人生活漫畫、虛構通知、模擬購物 App、圈選與逐步揭示；圖像與文字／介面分開。
- 上一頁、下一頁、章節、暫停、揭示與收起；揭示不自動跳頁。選項不計分、不顯示能力診斷或排名。
- 帶領者備課獨立一頁，含完整逐頁教案、教學節奏與 9 個官方參考連結；最後查證日 2026-10-15。上課頁沒有隱藏講師面板，揭示後投影皆可見。
- 本分頁 sessionStorage 記住頁碼、各頁揭示與選擇；返回與重新載入可續課。關閉分頁後可能清除，無雲端儲存或追蹤。
- 不讀取原首頁難度，不要求真實個資。投影課程內沒有可操作 URL、QR code 或資料輸入。

## 入口

- `/#lectures`：主題首頁
- `/#lectures/prepare`：備課資料
- `/#lectures/lesson-01`：上課畫面

640×360 橫向時，先顯示故事與提問；「展開討論選項」切換成整幅選項區，保留大字與固定控制列。1280×720 同時顯示故事及選項。

## 安全與帶領

疑似詐騙查證找 165；銀行／卡片風險立即通知往來銀行；人身危險或需警察立即協助找 110，必要時可並行。已輸入資料或付款的事件應立即求助，不在課堂要求公開真實資料。答案比較查證品質，不以單一語句判定真假，也不把答題當作能力診斷。

第 2 頁為開場探索：「如果是你，會先怎麼做？」C 是「先回覆通知，詢問是否真的會退回」，解析說明仍屬同一未確認來源，需另從官方確認。
